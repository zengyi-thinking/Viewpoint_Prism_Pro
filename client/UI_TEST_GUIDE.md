# UI 优化快速测试指南

## 启动项目

```bash
# 进入客户端目录
cd client

# 安装依赖（如果还没有安装）
npm install

# 启动开发服务器
npm run dev
```

## 测试新主题

1. 打开浏览器访问 `http://localhost:7870`
2. 点击右上角的太阳/月亮图标
3. 尝试切换不同的主题：

### 深色主题
- Viewpoint 深色 (默认)
- 深度专注
- VS Code Dark
- VS Code Dark+
- NotebookLM

### 浅色主题 (新增)
- Viewpoint 浅色
- 柔和米白 ✨
- 清新薄荷 ✨
- 温暖沙色 ✨

## 测试响应式布局

在浏览器开发者工具中测试不同屏幕尺寸：

1. 打开开发者工具 (F12)
2. 切换到设备模拟模式 (Ctrl+Shift+M)
3. 测试以下分辨率：
   - 桌面: 1920x1080, 1440x900, 1280x720
   - 平板: 768x1024
   - 手机: 375x667, 414x896

## 测试组件样式

### 按钮组件
访问任何包含按钮的页面，测试：
- hover 效果
- active 效果（点击时）
- focus 效果（Tab 键导航）

### 输入框
测试表单输入：
- hover 效果
- focus 效果（应该有蓝色光晕）
- 输入文字的可读性

### 卡片和面板
观察：
- 边框圆角
- 阴影效果
- hover 时的微动画

## 测试工作台

1. 登录后进入项目工作台
2. 测试面板拖拽调整大小
3. 测试面板折叠/展开
4. 切换不同的棱镜（知识、创作、译制、衍射）
5. 观察动画过渡效果
