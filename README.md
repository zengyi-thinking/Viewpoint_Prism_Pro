# Viewpoint Prism Pro

Viewpoint Prism Pro 是一个“视频内容工作台”。同一条视频在一个统一界面中被并行处理为四种资产流：学习、二创、译制、分发。

- `知识棱镜`：视频 -> 结构化知识资产
- `创作棱镜`：视频/文案 -> 节点化可控二创视频
- `译制棱镜`：视频 -> 多语种本地化版本
- `衍射棱镜`：视频 -> 多平台图文分发内容

## 1. 产品特色（来自 Excalidraw 需求拆解）

- 一个工作台，四种生产模式：不切换系统，切换右侧棱镜即切换产线。
- 中央播放器 + 底部对话框 + 右侧棱镜面板强联动：不是“问答外挂”，而是“可落盘的生产动作”。
- BYOK 架构：用户自带模型密钥，按任务自由组合 ASR、LLM、多模态、生图、生视频、TTS。
- PrismFlow（Git 式分支）：视频生成进入可回退、可分支、可合并的工程流。

## 2. 工作台界面（重点）

> 介绍页与工程创建页不展开。核心说明主工作台。

### 2.1 全局布局

- 左侧：`视频源 + 搜索栏 + 视频列表 + 可勾选分析项`
- 中间：`视频播放窗口 + 对话窗口`
- 右侧：`棱镜入口区（知识/创作/译制/衍射） + 动态展开面板`
- 右上：`Setting（模型 API Key、引擎状态）`

### 2.2 统一交互原则

- 点击任一棱镜图标，右侧区域从图标态平滑展开为“专用控制台”。
- 中间对话框不仅回答问题，还会把结果写入当前棱镜的时间轴/任务流。
- 每个棱镜最终都提供“可导出资产”，不是只给文本回复。

### 2.3 工作台组件创建清单（工程可执行）

- `WorkbenchShell`：三栏布局容器，负责左右区伸缩与响应式布局。
- `VideoSourcePanel`：视频源管理、搜索、筛选、勾选分析任务。
- `PlayerCenter`：播放器主体，暴露当前时间、暂停/播放、片段选区事件。
- `ChatDock`：底部对话输入、快捷指令、历史问答流。
- `PrismSwitcher`：右侧四棱镜入口与激活态切换。
- `PrismPanelHost`：承载各棱镜专用面板，统一处理展开/收起动画与状态保留。
- `SettingsGate`：BYOK 密钥管理、连通性检测、引擎状态灯（绿/黄/红）。

### 2.4 全局状态机（建议）

- `Idle`：未选择视频。
- `VideoReady`：视频已加载，等待棱镜动作。
- `PrismActive`：某棱镜面板已展开并接管右侧区域。
- `TaskRunning`：当前棱镜有后台任务执行（转写/抽帧/渲染/翻译/导出）。
- `Reviewing`：用户在中间对话框进行人工校正。
- `ExportReady`：资产已可导出或同步。
- `Failed`：任务失败，可重试、回滚或切换模型。

## 3. 四大棱镜能力

### 3.1 知识棱镜（Knowledge Board）

#### 目标

面向深度学习者，把“看视频”变成“生成可复习知识库”。

#### 工作流

1. 用户在左侧选中学习视频并播放，点击 `知识棱镜`。
2. 右侧展开知识看板，出现 `Sync to Notion/飞书` 按钮。
3. 播放过程中系统持续抓取关键帧（PPT/白板/图表）并同步生成结构化大纲。
4. 用户在中间对话框提问，Q&A 自动回填右侧笔记时间轴。
5. 点击“一键结算”，输出完整学习资产。

#### 最终产物

- 图文并茂 Markdown 大纲（H1/H2/H3 自动排版）
- 融合聊天记录的个性化学习笔记（按用户画像裁剪难度）
- 记忆闪卡 + 基于遗忘曲线的复习计划
- 带时间戳跳转信息的 Notion/飞书同步内容

#### 关键功能创建清单

- 实时逐字稿服务（带时间戳）
- 关键帧检测与去重（PPT/板书/图表示例优先）
- 章节切分与摘要压缩（过滤口语噪音）
- 对话内容注入笔记时间轴（Q&A 卡片）
- 一键结算导出（Markdown + Flashcards + Sync）

### 3.2 创作棱镜（PrismFlow）

#### 目标

面向二创作者，把“一次性生成”升级成“节点化工程可控生成”。

#### 三大特色（画板原始定义）

- 类 Git 的节点化版本控制（Branch / Merge）
- 首尾帧精准锚定（Skill Checkpoints）
- BYOK 开放架构（用户自由配置模型组合）

#### 六步交互旅程

1. 空间折叠：主界面左收缩，右侧进入暗色无限画布。
2. 风格注入：导入优秀案例，提取运镜/节奏/滤镜形成 Style Preset。
3. 拆解分镜：文案切片生成 Main Branch（Node 1...N）。
4. 节点微调：每个 Node 暴露 `起幅图/动态补全/落幅图` 三段式控制。
5. 局部渲染与分支：Node 不满意时新建分支二次渲染，完成后 Merge。
6. 串联导出：全部节点完成后调用 FFmpeg 自动缝合并对齐音轨。

#### 最终产物

- 可追溯节点工程文件（主干+分支历史）
- 可复用风格预设
- 成片视频（含解说与背景音效自动对齐）

#### 关键功能创建清单

- Node 数据结构（状态、Prompt、首尾帧、渲染结果、父子关系）
- 分支图管理（新建分支、差异对比、合并策略）
- 首尾帧锁定与中间动态补全接口
- 节点级渲染队列（可并行、可取消、可重试）
- 全局串联导出流水线（FFmpeg）

### 3.3 译制棱镜（Localization Workbench）

#### 目标

面向跨语种搬运与出海场景，完成“字幕 + 配音 + 画面文字本地化”。

#### 工作流

1. 选中源视频，点击 `译制棱镜`。
2. 右侧展开“双语对照与配音控制台”（左原文，右译文）。
3. 用户通过中间对话框执行语境润色（例如带货口语化）。
4. 系统检测画面硬字幕，提示是否擦除并替换目标语言文案。
5. 点击“一键译制”导出多语资产。

#### 最终产物

- 双语字幕文件（`.srt` / `.vtt`）
- 克隆音色配音轨（保留情绪与节奏）
- 视觉纯净版 / 嵌字替换版视频

#### 关键功能创建清单

- ASR + 句级时间轴切块
- 术语表/风格词典驱动翻译
- 对话驱动翻译改写（实时回写右侧文本）
- OCR + Inpainting + 文本重贴图层
- TTS/Voice Clone 与口型/节奏对齐

### 3.4 衍射棱镜（Content Diffusion）

#### 目标

面向运营分发场景，把长视频“降维重排”为平台适配图文包。

#### 工作流

1. 点击 `衍射棱镜`，右侧展开多平台裂变控制台。
2. 顶部平台标签：`小红书/即刻`、`Twitter/X Thread`、`Newsletter/公众号`、`LinkedIn`。
3. 系统自动筛选 4-6 张高质量关键帧进入素材暂存区。
4. 用户通过对话框做“主编级微调”（语气、情绪、受众）。
5. 点击“一键生成多端资产”批量导出。

#### 最终产物

- 社交短图文包（如小红书/Instagram）
- 连续长推文 Thread（如 X/即刻）
- 深度长文（如 Newsletter/公众号/博客）

#### 关键功能创建清单

- 平台模板系统（字数、风格、结构约束）
- 关键帧美学评分与裁剪（1:1 / 3:4 等比例）
- 多版本文案生成与对比（Hook/正文/结尾 CTA）
- 平台语境改写器（语气迁移、Emoji 策略）
- 批量导出与发布适配（文本+配图元数据）

## 4. 对话窗口的系统级角色

中间对话框是“跨棱镜编排器”，不是独立聊天框。

- 在知识棱镜中：生成补充解释并写入学习笔记时间轴。
- 在创作棱镜中：用于节点 Prompt 微调与风格指令。
- 在译制棱镜中：用于语境本地化和术语校准。
- 在衍射棱镜中：用于平台化文案改写与受众定调。

## 5. 技术架构（BYOK）

所有模型密钥来自右上角 `Setting`，系统按任务路由调用。

- 听觉基建：Whisper v3 / 火山 / 阿里云 ASR
- 视听多模态：Gemini / GPT-4o 等
- 生图：Midjourney 等图像生成能力
- 生视频：Seedance 等视频模型
- 语音合成：ElevenLabs 类 TTS/克隆服务
- 外部同步：Notion API、飞书开放平台 API
